Quais são as principais competências técnicas de Nattan Ferreira Lopes?

Nattan é graduando em Engenharia de Computação pela UFERSA e possui formação técnica em TI pelo IFRN. Tem experiência no desenvolvimento de sistemas embarcados e IoT (ESP32, Arduino, sensores, comunicação celular), além do desenvolvimento web full stack utilizando Python (Flask), JavaScript (React, Next.js, Tailwind CSS), C, SQLite e controle de versão com Git/GitHub.

Quais projetos foram desenvolvidos por Nattan?

Qual é a formação acadêmica de Nattan Ferreira Lopes?
